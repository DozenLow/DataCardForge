# 决策：阻塞闸门——冻结传播、弹出一次性告警、红框标出节点

- **日期**：2026-11-17
- **状态**：✅ 已实施（`blockers` 派生、`propagationFrozen`、告警音/桌面通知/标题闪烁、`card--blocked`）
- **标签**：`#前端 #可靠性 #阻塞 #脚本卡 #无障碍`
- **结论**：环境类与结构类问题（环境戳不一致、运行时缺失、后端离线/协议不匹配、成环拒绝、
  列数契约破坏）会让图**无法继续推进**——此时冻结**自动传播**，弹一次带声音的对话框、
  尽力弹桌面通知、闪烁标题、把**节点级**问题的那张卡红框标出；一切结果与运行状态保留，
  问题消失后**自动解除**。计算错误（语法、运行错）**不算阻塞**：它留在卡片自己的红态与
  诊断面板里，否则每打错一个字符都会让整个工作台停摆。
- **上游决策**：[脚本卡自动运行](2026-11-17-script-autorun.md)（阻塞期间必须冻结）、
  [工作区信任](2026-11-17-workspace-trust.md)（不可达≠许可）、
  [后端持有计算](2026-10-17-backend-owns-compute.md)（降级必须可见）

## 核心表述

> 被阻塞时不要"继续执行"——继续只会产出错误结果。停下来、把原因喊出来、把能保留的都
> 保留；原因消失后自己恢复。红框只框"这一张卡卡住了"的节点级问题；环境级问题用对话框
> 和横幅说清楚，不假装是哪张卡的错。

## 背景（这一轮修的是什么）

自动运行落地后，一次数据流推进可能跨很多卡片；环境戳不一致、Python 运行时缺失、后端
离线这类问题不会让某一张卡报错，而是让**整条链**停在半路：有的卡算完、有的卡在等、还有
的卡的结果来自上一个环境。此前这些状况只有横幅或单卡红态，用户容易在"看起来还在跑"的
界面里做出错误判断。

## 决策内容

1. **四类阻塞**（`BlockerKind`）：
   - `envMismatch`：工作区环境戳与本机不一致（脚本保持手动）；
   - `runtimeMissing`：某次脚本运行报告未找到 Python 运行时；
   - `backendOffline` / `backendMismatch`：后端不可达 / 协议不匹配；
   - `cycle` / `columnContract`：节点错误码为成环拒绝或列数契约破坏（节点级，带 `cardId`）。
   **计算错误不在其中**（`divisionByZero`、语法错等）。
2. **只冻结传播**。冻结的是"自动运行与自动推进"（`propagationFrozen` 让
   `maybeAutoRunScript` 直接返回）；**不**取消在途任务、**不**冻结编辑、**不**断开事件流
   （否则无法自动恢复），也不清任何结果。
3. **自动解除**。`blockers` 由 store 派生（订阅一次，纯函数计算）；条件消失后为空，
   冻结随之解除，下一次脏事件照常推进。**没有「继续」按钮**：被阻塞时继续执行只会产生
   错误结果；对话框的「知道了」只关闭对话框，不解除阻塞。
4. **一次性告警**。新的阻塞（按 `kind + cardId` 去重）触发：页内模态（必须可读、列出
   原因）、两音提示（首次手势后创建 `AudioContext`，失败静默）、桌面通知（有权限才发，
   无权限时模态里提供「开启桌面提醒」按钮，权限请求发生在点击手势里）、标题闪烁 6 秒。
   同一阻塞只响一次，解除后同一阻塞再次出现会重新告警。
5. **红框只框节点级**。`card--blocked` 红色描边加在带 `cardId` 的阻塞卡上；环境级阻塞没有
   "有问题的那张卡"，由对话框与横幅说明，不随便挑一张卡背锅。
6. **保留一切状态**。结果、运行记录、编辑器内容、依赖图都不动；用户可以在阻塞期间继续
   编辑、手动重算（手动动作不经过传播冻结）。修复路径就是用户改配置/修脚本/等后端。
7. **「特殊声明」只记录不实现**。将来若需要"某个阻塞已知情、允许继续"，预留的是
   **卡片级** `allowBlocked?: boolean`（持久化、无 UI）加一个 store 层策略函数
   `isBlockingAllowed(card)`，默认恒 false；本阶段不写任何相关代码，也不加 UI。
8. **无障碍**：对话框有 `role="dialog" aria-modal="true"` 与可聚焦的关闭按钮；声音不是
   唯一提示（标题闪烁与页内对话框都在），系统 `prefers-reduced-motion` 不额外加动画。

## 不变量（改这块时不许破）

- 计算错误不得阻塞工作区；只有环境/结构问题可以。
- 阻塞只冻结自动传播：不取消在途、不冻结编辑、不断事件流、不清结果。
- 阻塞消失必须自动解除；没有"忽略并继续"的按钮。
- 节点级阻塞红框该卡；环境级阻塞不框任何卡。
- 同一阻塞（kind+cardId）只告警一次；解除后再次出现重新告警。
- 告警音/桌面通知是尽力而为：权限被拒、无音频上下文、无通知守护进程都不能变成错误。
- 自动运行在冻结期间绝不发起；手动运行仍允许（用户明确要求）。
- 「特殊声明」接口只存在于决策记录里，代码里不得出现提前落地的开关。

## 门禁

- `web/tests/BlockingGate.dom.test.tsx`：环境不一致升起对话框并冻结；「知道了」只关对话框
  （冻结保持）；原因消失自动解除；新种类的阻塞重新升起；计算错误不升起。
- `web/tests/ScriptCardStore.test.ts`（阻塞组）：环境不一致 / 恢复、成环节点阻塞与恢复、
  计算错误不阻塞、运行时缺失、冻结期间自动运行不发起。
- `web/tests/ScriptCard.dom.test.tsx`：节点级阻塞给卡片加 `card--blocked`，恢复后移除。
- 手动冒烟（浏览器）：环境不一致时对话框 + 音效 + 标题闪烁；修好后自动恢复传播。
